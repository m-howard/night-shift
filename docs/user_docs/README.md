# End-User Documentation

These pages are for repository owners and workflow authors who run jobs on the managed GitHub Actions runner platform. Use them to choose runner labels, set up workflows, build container images, and gather the right details when you need help.

## Start Here

| Document | Description |
| --- | --- |
| [Developer Quickstart](quickstart.md) | Run your first job on the platform with working examples for standard CI, arm64, and coding-agent workflows. |
| [Runner Label Catalog](runner-label-catalog.md) | Choose the right label based on workload type, architecture, duration, and storage limits. |
| [Docker Build Guide](docker-build-guide.md) | Build and push container images with `docker buildx`, remote caching, and the supported runner labels. |
| [Networking and External Access](networking-proxy-guide.md) | Understand which outbound destinations usually work, what blocked access looks like, and what to send in an access request. |
| [Troubleshooting Guide](troubleshooting.md) | Work from GitHub Actions symptoms, confirm the most likely cause, and collect the evidence support needs. |
| [Runner Access and Label Requests](runner-label-request.md) | Request repository access, a new label, more capacity, or additional outbound access. |
